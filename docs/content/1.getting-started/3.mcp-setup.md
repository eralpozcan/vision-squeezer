VisionSqueezer ships an MCP (Model Context Protocol) server that exposes image optimization as a tool your AI agent can call. Thanks to `npx -y`, no global install is required.

::callout{icon="i-lucide-triangle-alert" color="warning"}
Installing the server does not shrink images you paste or attach in the chat. The agent has to call the tool with an image path, or read the image from a project file (the Claude Code hook covers that). See [where it saves tokens](/guides/token-budget#where-it-saves-tokens).
::
 The server applies a **1600-token budget by default**, see the [token budget guide](/guides/token-budget).

## One command

Pick your client and run the line. Each one registers the server for you.

| Client | Command |
| --- | --- |
| Claude Code | `claude mcp add vision-squeezer -- npx -y vision-squeezer` |
| Codex CLI | `codex mcp add vision-squeezer -- npx -y vision-squeezer` |
| Gemini CLI | `gemini mcp add --scope user vision-squeezer -- npx -y vision-squeezer` |
| Qwen Code | `qwen mcp add vision-squeezer -- npx -y vision-squeezer` |
| Kimi CLI | `kimi mcp add vision-squeezer -- npx -y vision-squeezer` |
| VS Code | `code --add-mcp '{"name":"vision-squeezer","command":"npx","args":["-y","vision-squeezer"]}'` |
| Cursor | `npx vision-squeezer install --client cursor --yes` |
| Windsurf | `npx vision-squeezer install --client windsurf --yes` |
| Claude Desktop | `npx vision-squeezer install --client claude-desktop --yes` |
| OpenCode | `npx vision-squeezer install --client opencode --yes` |

The `code --add-mcp` line adds the server to your VS Code user profile and works in macOS and Linux shells. On PowerShell, escape the quotes as in the [VS Code docs](https://code.visualstudio.com/docs/copilot/customization/mcp-servers).

### Installer

The installer picks the right command, pins the version, and handles scope for Claude Code, Codex, Qwen, OpenCode, Gemini, Kimi, Cursor, Windsurf, Claude Desktop, and VS Code. For Cursor, Windsurf, Claude Desktop, and OpenCode it merges one entry into the JSON config: your other servers are kept, and a file it cannot parse (for example one with comments) is left untouched.

```bash [Terminal]
npx vision-squeezer install                              # interactive
npx vision-squeezer install --client codex --yes         # scripted
npx vision-squeezer install --client claude --method plugin --yes   # bundles the /vision-stats, /vision-doctor, /vision-upgrade skills
```

## Manual configuration

Prefer editing the file yourself, or use Zed (not in the installer: its `settings.json` allows comments)? Add one entry and restart the editor.

::tabs
  :::tabs-item{label="Cursor" icon="i-simple-icons-cursor"}
  Add to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` (this project):

  ```json
  {
    "mcpServers": {
      "vision-squeezer": {
        "command": "npx",
        "args": ["-y", "vision-squeezer"]
      }
    }
  }
  ```
  :::

  :::tabs-item{label="VS Code" icon="i-lucide-code"}
  Prefer the `code --add-mcp` line above. To share the server with your team, commit a `.mcp.json` at the project root:

  ```json
  {
    "mcpServers": {
      "vision-squeezer": {
        "command": "npx",
        "args": ["-y", "vision-squeezer"]
      }
    }
  }
  ```

  Or run **MCP: Add Server** from the Command Palette.
  :::

  :::tabs-item{label="Windsurf" icon="i-lucide-wind"}
  In the Cascade panel, open the `...` menu and choose **Open MCP config file** (usually `~/.codeium/windsurf/mcp_config.json`), then add:

  ```json
  {
    "mcpServers": {
      "vision-squeezer": {
        "command": "npx",
        "args": ["-y", "vision-squeezer"]
      }
    }
  }
  ```

  This applies to the Cascade agent. Windsurf's Devin Local agent reads the Devin CLI config instead.
  :::

  :::tabs-item{label="Zed" icon="i-simple-icons-zedindustries"}
  Open **Settings → AI → MCP Servers → Add Server**, or run `zed: open settings file` and add:

  ```json
  {
    "context_servers": {
      "vision-squeezer": {
        "command": "npx",
        "args": ["-y", "vision-squeezer"]
      }
    }
  }
  ```
  :::

  :::tabs-item{label="Claude Desktop" icon="i-simple-icons-anthropic"}
  Add to `claude_desktop_config.json`:

  - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
  - Windows: `%APPDATA%\Claude\claude_desktop_config.json`

  ```json
  {
    "mcpServers": {
      "vision-squeezer": {
        "command": "npx",
        "args": ["-y", "vision-squeezer"]
      }
    }
  }
  ```
  :::

  :::tabs-item{label="OpenCode" icon="i-lucide-terminal"}
  `opencode mcp add` is interactive-only, so use `npx vision-squeezer install --client opencode --yes`, or add to `~/.config/opencode/opencode.json`:

  ```json
  {
    "mcp": {
      "vision-squeezer": {
        "type": "local",
        "command": ["npx", "-y", "vision-squeezer"],
        "enabled": true
      }
    }
  }
  ```
  :::

  :::tabs-item{label="Codex (TOML)" icon="i-lucide-file-cog"}
  Add to `~/.codex/config.toml`:

  ```toml
  [mcp_servers.vision-squeezer]
  command = "npx"
  args = ["-y", "vision-squeezer"]
  ```
  :::
::

More editors (JetBrains, Kiro, Antigravity) are listed in the [README](https://github.com/eralpozcan/vision-squeezer#installation).

## MCP tools

Once registered, the server exposes three tools:

| Tool | Purpose | Key args |
| --- | --- | --- |
| `optimize_image` | Standard optimization. Returns the optimized image plus a short JSON report | `image_path` (preferred) or `image_base64`, `target_model` (core profiles plus `kimi`, `glm`, `pixtral`, `gemma`, `internvl`, `llava`, `minimax`, and other catalog aliases), `max_tokens` (token budget, default `1600`, `0` disables), `mode` (`standard` / `ocr` / `auto`; only `ocr` drops colour), `output_format` (`jpeg` / `webp` / `avif`) |
| `sandbox_execute` | Think-in-Code: run atomic ops locally | `operations[]` — `crop`, `grayscale`, `binarize`, `resize`, `contrast`, `brightness` |
| `get_savings_stats` | Cumulative token / USD savings | — |

::callout{icon="i-lucide-triangle-alert" color="warning"}
The snippets on this page omit the version for brevity. Pin it (`npx -y vision-squeezer@X.Y.Z`, or `@latest`) in shared configs: an unpinned `npx` cache can freeze users on whatever tarball resolved first. The installer pins for you.
::

## Verify

Restart the client, then ask it to list its MCP tools. You should see `optimize_image`, `sandbox_execute`, and `get_savings_stats`. To check the package itself:

```bash [Terminal]
npx -y vision-squeezer --version
```

If the MCP server fails to connect, run `vision-doctor` (Claude Code skill) — it probes the registered command and surfaces the root cause.
